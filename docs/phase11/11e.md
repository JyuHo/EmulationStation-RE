## Objectif

Rendre les **options de thème** utilisables : menu « Options du thème », réglage de région,
enregistrement dans `es_settings.cfg`, rechargement à chaud, traductions.

## Code

- `optionSettingKey` (`ThemeOptions.cpp`) et son test `[11e]` : déjà écrits en 11b ; vérifie-les, ne les réécris pas.
- `Settings` : une lecture de chaîne qui n'écrit pas `[ERROR]` quand la clé est absente (par
  exemple `getStringOr(name, défaut)` ou `hasString`), avec son test.
- `ThemeData::loadFile` lit les options enregistrées du jeu de thèmes courant et les passe dans
  `LoaderContext::selectedOptions` ; région : réglage `ThemeRegion` (`us`/`eu`/`jp`, défaut `eu`).
- Menu « Interface » (`GuiMenu`) : entrée « Options du thème » **seulement** si le thème
  courant a au moins une option ; elle ouvre une liste d'options (titre et aide localisés du
  thème, choix avec leur `displayName`). Entrée « Région du thème » **seulement** si le thème
  utilise l'attribut `region`. Sinon le menu est identique à aujourd'hui (écran 06, R5).
- Validation : enregistre le choix, recharge les thèmes, `ViewController::reloadAll()`, comme
  le changement de jeu de thèmes existant. Pas de redémarrage.
- Chaînes affichées par `_()` (titres de menu) ; les textes venant du thème ne passent pas par
  gettext (ils sont déjà localisés par le thème). `.pot` régénéré (`es-update-pot`), `.po`
  `fr`, `de`, `es`, `it` complétés (`test_Translations` vert).

## Captures des nouveautés (à créer dans cette PR)

Le job « Screenshots vs base branch » lance le script de la PR avec les deux binaires : un
écran qui utilise une nouveauté diffère forcément de la base (PROMPT.md 14.8). D'où :

- `tests/data/capture-themes/` : ES_HOME de test (comme `tests/data/capture/`), avec un thème
  format 4 **original** dont chaque écran isole une propriété, en formes unies sur fond
  contrasté (rectangles d'images d'une couleur, pas de texte antialiasé là où l'on sonde) ;
- `tests/smoke/capture-themes.sh <binaire> <dossier>` : comme `capture.sh` (Xvfb, xdotool,
  `SDL_AUDIO_DRIVER=dummy`, `ES_GL_DEBUG=1`, échec sur `[ERROR]`), qui prend les écrans **et**
  vérifie des sondes ;
- `tests/smoke/probe.sh <png> <x> <y> <RRGGBB> [tolérance]` : lit un pixel (ImageMagick
  `convert … -format '%[pixel:p{x,y}]' info:` ou équivalent) et échoue s'il s'écarte de plus de
  la tolérance par canal ;
- sondes minimales : `zIndex` (zone de recouvrement de deux rectangles : couleur de celui du
  dessus, et l'inverse quand on échange les `zIndex`), rotation (un point dans le rectangle
  tourné et pas dans le rectangle droit, et l'inverse), `rotationOrigin`, `disabled` (couleur
  du fond) ;
- CI : étape « Theme screenshots (Xvfb) » dans le job `arch` (les deux compilateurs), artefact
  envoyé ; dans le job « Screenshots vs base branch », comparaison base/tête avec le
  `capture-themes.sh` **et le fixture de la base** (ce que la base sait déjà faire doit rester
  identique), **seulement si la base contient déjà ce script**
  (`git -C "$RUNNER_TEMP/base" ls-files --error-unmatch tests/smoke/capture-themes.sh`) ; elle
  devient donc active à partir de 11e.

## Code

- Le rendu ne passe que par l'API de `renderer/Renderer.h` (aucun GL hors de `renderer/`,
  étape CI existante). La rotation est une matrice (`glm`), pas un nouvel appel GL.
- `zIndex` : les vues trient leurs composants selon le `zIndex` (valeurs par défaut de
  `docs/THEMES.md`) ; un tri **stable**, pour que les thèmes format 3 sans `zIndex` gardent
  exactement leur ordre actuel (R5).
- Propriété absente = comportement actuel inchangé (R5).

## Tests

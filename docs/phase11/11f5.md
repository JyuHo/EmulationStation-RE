## Objectif

Décision du propriétaire (01/11/2026) : l'élément `keyboard` des thèmes Recalbox a un effet ici.
ES n'a pas de clavier virtuel (la saisie passe par `GuiTextEditPopup` et un clavier physique) :
cette PR en crée un, **original** (aucune ligne ni disposition copiée des trois claviers de
Recalbox, R3), et le rend thémable.

Prérequis : 11f1 à 11f4 fusionnées (`KeyboardTheme::fromTheme(theme, view)`, thème principal
gardé par `Window`, fermeture par `closeGui`).

## Faits de Recalbox (sources 10.1.1, référence seulement)

- Élément `keyboard`, type `keyboard`, lu dans le **thème principal**, dans la vue au-dessus de
  laquelle le clavier s'ouvre : `system` (liste des systèmes), nom de la vue de liste de jeux
  (`basic`, `detailed`…), `gameclip`, sinon `menu` (`WindowManager.cpp:131-145`,
  `guis/VirtualKeyboardTheme.cpp:9-17`).
- Propriétés (`VirtualKeyboardTheme.cpp:19-32`) et rôle (`VirtualKeyboardTheme.h:17-25`) :
  `keyColor` fond d'une touche, `keySelectedColor` fond de la touche sélectionnée,
  `keyTextColor` texte d'une touche, `keyDisabledColor` texte d'une touche désactivée,
  `keyModifierColor` majuscule active pour une lettre, `keyModifierLockedColor` majuscule
  verrouillée, `keyTitleColor` titre, `keyEditTextColor` texte saisi, `fontPath` police.
- Valeurs sans thème (`VirtualKeyboardTheme.h:17-24`) : `0x303030F0`, `0xC02020FF`, `0xFFFFFFFF`,
  `0x707070FF`, `0x4488FFFF`, `0x224488FF`, `0xFFFF80FF`, `0xFFFFFFFF` ; police : celle du projet.
  Ces huit couleurs sont reprises comme valeurs par défaut (des nombres, pas du code), sources
  citées dans `THEMES.md`.
- Aucune taille n'est thémable (`VirtualKeyboardTheme.h:2-5`).

## Conception imposée (le propriétaire peut l'ajuster dans la PR brouillon)

- **Réglage** `VirtualKeyboard` (booléen, `Settings.cpp`), **faux par défaut** : la saisie
  actuelle ne change pas et la capture `08-text-input` reste à 0 pixel (R5). Interrupteur
  « Virtual keyboard » dans « UI settings » (`_U()`, traduit).
- Réglage vrai : les deux appels de `GuiTextEditPopup` (`GuiMetaDataEd.cpp:123`,
  `ScraperSearchComponent.cpp:473`) ouvrent `GuiVirtualKeyboard` à la place, avec les **mêmes**
  paramètres (titre, valeur initiale, rappel d'acceptation, multiligne). Une seule fonction de
  choix (par exemple `openTextInput(...)`), pas deux `if`.
- **`GuiVirtualKeyboard`** (`es-core/src/guis/`) :
  - cadre et fond comme les autres fenêtres (11f2), titre en `keyTitleColor`, zone du texte
    saisi en `keyEditTextColor` ;
  - grille de touches : chiffres `1`…`0` ; lettres en disposition QWERTY sur trois rangées ;
  `-` `_` `.` `'` ; dernière rangée : MAJ, ESPACE, EFFACER, OK, ANNULER ;
  - MAJ : un appui = la prochaine lettre en majuscule (`keyModifierColor`), deux appuis =
    verrouillé (`keyModifierLockedColor`), trois = désactivé ;
  - navigation : croix directionnelle d'une touche à l'autre, avec retour à l'autre bord ;
    `a` = appuyer ; `b` = annuler (fermer sans rien changer) ; `y` = effacer un caractère ;
    `start` = OK ; aide en bas d'écran pour ces quatre boutons ;
  - multiligne : OK valide, pas de touche « retour à la ligne » (écrit dans `THEMES.md` comme
    limite) ;
  - `keyDisabledColor` : lu, sans touche désactivée dans cette disposition (écrit dans
    `THEMES.md`) ;
  - fermeture par `mWindow->closeGui(this)` (11f3), jamais `delete this` ;
  - couleurs lues **à l'ouverture** : `KeyboardTheme::fromTheme(thème principal, vue)`, chaque
    valeur absente prenant la valeur de Recalbox ci-dessus ; vue choisie par une fonction pure
    selon l'état de `ViewController` (règle de `WindowManager.cpp:131-145`).
- Tailles (touches, police) : décidées par le clavier, proportionnelles à l'écran, écrites en
  constantes nommées au même endroit.

- Modèle : déplacements avec retour au bord sur chaque rangée ; saisie d'une lettre, d'un
  chiffre, d'un espace ; effacer sur un texte vide (rien) ; cycle MAJ (une lettre en majuscule

- `capture-themes.sh` : `es_settings.cfg` du fixture avec `VirtualKeyboard` vrai ; thème
  principal des sondes avec un élément `keyboard` dans la vue de liste de jeux utilisée
  (`keyColor` et `keySelectedColor` unis et distincts). Écran ajouté **à la fin** :
  `NN-keyboard`, ouvert depuis l'éditeur de métadonnées d'un jeu (touches commentées) ; sondes :

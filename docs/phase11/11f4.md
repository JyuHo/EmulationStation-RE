## Faits de Recalbox (sources 10.1.1, référence seulement, R3)

Icônes (`es-app/src/guis/menus/base/Menu.cpp:309-337`) :
- dessinées seulement si l'entrée a une icône valide (`:311`, `:329`) ; **ici** : seulement si le
  thème donne l'image de ce type (pas d'icône par défaut, les images de Recalbox ne sont pas
  reprises, `MenuThemeData.h:142-168`) ;
- carré de côté `0,8 ×` la hauteur de la ligne, centré verticalement, à `marge` du bord gauche,
  `marge = 3 + largeur d'écran / 320` (`:38`, `:331-336`) ; le texte est décalé de
  `côté + marge` (`:312`, `:338`) ;
- teinte : couleur du texte, ou couleur sélectionnée sur la ligne sélectionnée (`:325`).

Icône de chaque entrée, d'après le menu de Recalbox (`data/resources/menu.xml`) :

| Entrée ES (`GuiMenu.cpp`) | Icône | Source |
|---|---|---|
| Scraper | `iconScraper` | `menu.xml:491` |
| Sound settings | `iconSound` | `menu.xml:466` |
| UI settings | `iconUI` | `menu.xml:417` |
| Configure input | `iconControllers` | `menu.xml:461` |
| Quit | `iconQuit` | `menu.xml:591` |
| Quit → Restart system | `iconRestart` | `menu.xml:132` |
| Quit → Shut down system | `iconShutdown` | `menu.xml:130` |
| Quit → Quit EmulationStation | aucune | pas d'équivalent chez Recalbox |

Aucune autre entrée ne reçoit d'icône. Les 15 autres propriétés `icon…` restent lues sans
effet (entrées absentes d'ES) : écris-le dans `THEMES.md`.

En-têtes de section (`es-app/src/guis/menus/base/ItemHeader.h:94-153`) :
- une ligne du menu, sélectionnable, sans action (`:58-69`) ;
- texte en majuscules avec la marque d'ouverture `▼ ` : après le texte si l'alignement est à
  gauche, avant sinon (`:146-153`) ;
- couleur `section.color`, ou `section.selectedColor` quand la ligne est sélectionnée (`:98`) ;
- un trait de 2 px (1 px à 480p ou moins, `:22`, `:99`) au milieu de la ligne : à droite du
  texte (aligné à gauche), à gauche (aligné à droite), des deux côtés (centré) ;
  écart `largeur d'écran / 160` (`:20`, `:100-121`) ;
- valeurs absentes : celles de `menutext` (copie, 11f1), alignement centré.

Seul en-tête de Recalbox qui a un équivalent ici : « `<nom du thème>` CONFIGURATION » avant les
options du thème (`menu.xml:435-436`). **Ici** : dans « UI settings », juste avant les entrées
d'options de 11e2, **seulement** si le thème a des options. Libellé : `_U("{} configuration")`
avec le nom du jeu de thèmes (traduit dans `de`, `es`, `fr`, `it`).

## Conception imposée

- `GuiMenu::addEntry` prend un `MenuIcon` (valeur « aucune » possible). Si
  `getMenuTheme().icons` a ce type : une `ImageComponent` en premier élément de la ligne,
  `invert_when_selected` comme le libellé, teinte `text.color.value_or(0x777777FF)`. Sinon : la
  ligne est construite **exactement** comme aujourd'hui. Les lignes du sous-menu « Quit » sont
  construites à la main (`GuiMenu.cpp:368-399`) : même règle, par une fonction commune plutôt
  que trois copies.
- `MenuComponent::addSection(const std::string& label)` (et `GuiSettings::addSection`) : une
  ligne dont l'élément dessine texte et traits selon les faits ci-dessus. La marque `▼` doit
  exister dans la police ; si elle n'y est pas (un carré vide à l'écran) : **STOP**, capture à
  l'appui.
- La couleur de la ligne sélectionnée passe par le `setColor` virtuel de 11f2 (barre thémée)
  ou par l'inversion actuelle (barre d'origine).

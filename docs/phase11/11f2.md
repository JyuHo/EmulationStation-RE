## Barre de sélection (`ComponentList`)

Deux comportements, choisis **une fois** par la présence des valeurs :

- **Aucune** de `text.selectorColor`, `text.selectedColor`, `backgroundColor` dans le thème :
  le code actuel **tel quel** (inversion `0xFFFFFFFF` `InvertDst`, `0x777777FF` `Additive`,
  bords de 2 px `0x878787FF`, séparateurs `0xC6C7C6FF` sauf si `text.separatorColor` est
  présent).
- **Au moins une** présente : la règle de Recalbox (`ComponentList.cpp:156-212`), les valeurs
  absentes parmi les trois prenant celles de Recalbox (`MenuThemeData.cpp:121` fond
  `0xFFFFFFFF`, `:124` sélecteur `0x878787FF` et sélectionné `0xFFFFFFFF`) :
  - barre dessinée seulement si `selectorColor != backgroundColor` et l'alpha de
    `selectorColor` n'est pas nul ;
  - un rectangle de la couleur du fond avec le mélange `dst × (1 − src)`, puis un rectangle de
    `selectorColor` en `Additive` ;
  - les éléments de la ligne sélectionnée dessinés avec `selectedColor` (puis leur couleur
    d'origine remise) ;
  - pas de bords de 2 px.

  Le mélange `dst × (1 − src)` n'existe pas dans `Renderer::BlendMode` : ajoute une valeur
  (par exemple `MultiplyInvSrc`, `glBlendFunc(GL_ZERO, GL_ONE_MINUS_SRC_COLOR)`) **dans
  `renderer/`**, rien hors de `renderer/` (étape CI existante). Pour recolorer une ligne,
  ajoute à `GuiComponent` `virtual void setColor(unsigned int)` et `virtual unsigned int
  getColor() const` (sans effet par défaut), redéfinis-les dans `TextComponent` (existe déjà en
  non virtuel) et `ImageComponent` (teinte) ; ne change pas le comportement de ces deux
  composants pour les autres appelants (tableau R16).

Écris ces deux comportements, la condition et les sources dans `THEMES.md` section 10.
